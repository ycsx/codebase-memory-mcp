## 移植前的复现与上游来源

### 1. TypeScript/Vue 导入目标

样例声明 npm 依赖 `ws`，同时在导入方旁边放了 `ws.ts` 和 `fs.ts`。两种规模的索引都把 npm 的 `ws` 和 Node 内置的 `fs` 连到这些同名文件，随后 `WebSocketServer()` 的构造调用和 `readFileSync()` 的调用也经 `import_map` 连错。对照项 `./util` 和 `./Widget.vue` 均指向真实文件。

带点的别名还有另一种表现。样例中的 `@app/cats/cat.service` 对应真实的 `src/cats/cat.service.ts`。小样例把它记为 `ExternalPackage`，加 60 个文件后则缺少这条导入边。移植时先按文件路径解析别名，再限制外部包的本地同名回退。fork 用 `ExternalPackage` 和导入边上的包名匹配跨项目依赖，应保留这部分信息。调用解析也要单独验收，样例中 npm 的 `connect()` 仍能经 `unique_name` 连到同名本地函数。[带点文件名及后续修正 #2975](https://github.com/DeusData/codebase-memory-mcp/pull/2975) · [ES 导入目标 #3038](https://github.com/DeusData/codebase-memory-mcp/commit/1862935360e7625f2746f56146fb3be5ae87c449)

### 2. Windows C/C++ 字符串续行

同一份 20 行 C++ 源码包含一个用反斜杠续行的字符串。LF 文件索引出 4 个函数，`Middle` 在第 10 行结束。仅将行尾改成 CRLF 后，`Middle` 延伸到第 20 行，`TrailerOne` 和 `TrailerTwo` 均消失。两种规模结果一致。

上游修复涉及两个解析入口。第一处在单文件提取前处理续行字节，保留总字节数与行号。第二处把同一处理用于 C/C++ 跨文件解析。移植后的验收应同时比较函数位置和跨文件调用边。[单文件提取修复](https://github.com/DeusData/codebase-memory-mcp/commit/5830c55c509df33313acd163b4293c56b1e2908c) · [跨文件解析修复](https://github.com/DeusData/codebase-memory-mcp/commit/8efb059fe8d40797eb91000439bda05802a99a1b)

### 3. Retrofit 客户端与服务端路由

Java 接口 `OrderApi.getOrder` 上的 Retrofit 注解 `@GET("v1/orders/{id}")` 描述出站请求。小样例生成 1 条 `HANDLES`，加 60 个文件后生成 2 条，两次均为 0 条 `HTTP_CALLS`。沿图查询会把客户端当成该接口的提供方。

建议一起移植上游的路径提取和接口判别。验收应覆盖 Retrofit 接口产生 `HTTP_CALLS`、JAX-RS 的 `@GET` 配合 `@Path` 保留 `HANDLES`，以及控制器类自带路径的 `@GET` 仍按服务端处理。本次本地样例验证了 Java 的误判，Kotlin 对照可沿用上游用例。[Retrofit 路径提取](https://github.com/DeusData/codebase-memory-mcp/commit/a031122a4dece52db1b8a41b3944ccab43acad19) · [接口判别](https://github.com/DeusData/codebase-memory-mcp/commit/c8c4b6c7dbb0ff87d3183b443e8190a3d79f642d)

### 4. 部署配置和普通 env 目录

完整索引漏掉了 `deploy/helm/values.yaml` 和 `app/env/settings.py`。同内容放在 `ops/helm/` 和 `app/settings/` 均有 File 节点。带 `pyvenv.cfg` 的真实虚拟环境也按预期被排除。

建议移植上游的目录判别。普通 `env/` 可以索引，虚拟环境由标记文件识别。`deploy/`、`deployed/` 只纳入支持的配置和脚本，继续过滤复制进去的程序源码和依赖清单。验收时应包含 fork 的 `.cbmignore` 覆盖规则，以及同一配置文件经完整、增量索引后的结果。[目录判别 #3037](https://github.com/DeusData/codebase-memory-mcp/commit/f9158d9e6ac24164a91403bf7a4cec0c93137ab9) · [增量回归](https://github.com/DeusData/codebase-memory-mcp/commit/a21efacfdebf29c170b3845666c05eef7a5341e5)
